# Personal Context RAG System

## Identity

**"나 자신을 위한 AI 컨텍스트 레이어"**

개인의 모든 정보를 자연어로 던지면, AI가 알아서 구조화하고 인덱싱하여,
어떤 AI 도구에서든 나의 컨텍스트로 활용할 수 있게 하는 시스템.

## Core Value

1. **Zero Friction Input**: 대충 던져도 AI가 정리
2. **Universal Access**: MCP로 어디서든 내 컨텍스트 접근
3. **Transparency**: 어떤 정보가 사용되었는지 추적 가능
4. **Portability**: 폴더 복사만으로 마이그레이션

## Differentiator

| 기존 도구 | 이 시스템 |
|-----------|-----------|
| 사용자가 정리해야 함 | AI가 알아서 구조화 |
| 검색 결과를 보여줌 | 대화의 컨텍스트로 주입 |
| 도구 안에서만 동작 | MCP로 어디서든 연결 |
| 블랙박스 | 사용된 정보 투명하게 노출 |
